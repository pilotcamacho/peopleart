## 8. Contact (`/contact`)

**Purpose:** Capture qualified inbound leads from all audiences.

**Form fields:**

| Field | Type | Required |
|-------|------|----------|
| Full name | Text | Yes |
| Organisation | Text | No |
| Email | Email | Yes |
| Inquiry type | Select: Enterprise Training / Investor / Government / Strategic Partner / Media / Other | Yes |
| Message | Textarea | Yes |
| Preferred language | Select: English / Spanish | No |

**Behaviour:**
- Server-side submission via `app/api/contact/route.ts`
- Email notification sent to `f.camacho@peopleart.co` via AWS SES
- Lead stored in DynamoDB regardless of inquiry type
- Success message shown in-page (no page reload)
- Rate limiting: max 5 submissions per IP per hour
